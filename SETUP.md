# Настройка бесплатного бота

Это версия с правилами, без платного AI/API. Работает на GitHub Actions независимо от ChatGPT и ноутбука. Собирает только общедоступные объявления Work.ua и robota.ua, если сайты допускают загрузку браузером и публикуют JobPosting. Не обходит капчи и блокировки. Telegram-каналы, Djinni, Jooble, отдельные сайты работодателей пока не подключены. Полное выполнение исходного промпта не гарантируется: отрасль и навыки определяются эвристиками, первая публикация и обновление не различаются, национальность компании и дорога не проверяются.

## Секреты

Settings → Secrets and variables → Actions → New repository secret:

1. `TELEGRAM_BOT_TOKEN` — токен от официального @BotFather.
2. `TELEGRAM_CHAT_ID` — числовой ID вашего личного чата. Можно узнать у Telegram-бота @userinfobot, который является сторонним сервисом: он увидит ваш общедоступный профиль Telegram. Альтернатива — локально вызвать getUpdates официального Bot API после сообщения своему боту; токен не публиковать в URL/логах/скриншотах.

Откройте своего бота и нажмите Start. Никаких токенов или chat ID в коде, README, issue или переписке.

## Проверка

Actions → Analyst jobs to Telegram → Run workflow → mode=test → Run workflow. Должно прийти тестовое сообщение. После этого повторите с mode=digest. Это первый реальный тест доступности сайтов из GitHub. Зелёная проверка Telegram не доказывает работоспособность поиска.

## Расписание

Два UTC-расписания с проверкой часового пояса Europe/Kyiv дают целевой запуск 09:01 зимой и летом. GitHub может задержать или пропустить запуск; точное получение сообщения в 09:01 не гарантируется. Сбор может занять несколько минут. GitHub отключает расписания публичных репозиториев после 60 дней без активности; потребуется возобновить workflow. История повторов в cache может быть удалена GitHub, в таком случае вакансии снова получат отметку впервые в отправках.

Дата из JobPosting считается датой сайта, не подтверждённой датой первой публикации. Без даты объявления не попадают в топ. Адреса левого берега исключаются по словарю; неизвестные адреса выводятся отдельно. Правый берег подтверждается только для распознанных адресов. Автоматическая оценка не заменяет проверку описания человеком.

Никто не контактирует с работодателями. Бот отправляет сообщения только в личный чат с ID из секрета.

Остановить: Actions → workflow → меню … → Disable workflow. Платёжные данные для публичного репозитория со стандартным ubuntu-latest не требуются.
